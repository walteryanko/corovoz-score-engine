# Security

This v0.1.0 engineering excerpt is not a production service. The current main branch is the scope for reported issues; no response SLA is promised.

For a vulnerability, use the repository's **Security → Report a vulnerability** option if private reporting is available. Do not post secrets, customer data, private media, credentials or an exploit against a live third-party system in a public issue. If private reporting is unavailable, open only a non-sensitive request for a private reporting channel. No private contact address is published here.

For ordinary defects, provide a minimal synthetic input, runtime version and expected/observed behavior. Functional tests do not establish a complete security guarantee. Dependency updates, untrusted-input isolation and authenticated integration remain host responsibilities.
