# Contributing

Use a minimal synthetic reproduction, explain the expected behavior and add a focused regression test for a behavior change. Run `npm test` and `npm run demo` after `npm ci --ignore-scripts`. Document changed scientific assumptions or capability boundaries.

Do not submit third-party scores, private media, customer data, credentials or model weights. Contributions to the licensed source are made under MPL-2.0; retain applicable notices. The private product is outside this repository's scope.
